# Nim-AI-
Project Goal: Create an AI model to play the game of Nim against 

MVP Scope: Code a q-learning model that I can play with in my terminal 

Schedule: 
    1. Set up Git repo and environment
    2. establish initial game setup (switch player, available actions methods, etc) 
    3. Create AI method: initialize, update, get_q_value() 
    4. Create AI method: update_q_value(), best_future_reward(),  choose_action()
    5. create training method, where the ai is in the training cycle and plays against itself. 
    6. create play method where the ai is playing against the human, navigate gameflow. 

Tech Stack: 
    1. python 
    2. maybe use numpy or pandas or pytorch.... maybe....
    3. user input into terminal, no fancy graphics 
    4. q-learning model as the AI
